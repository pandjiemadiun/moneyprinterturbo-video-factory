## Core Features 🎯

- [x] **Four usage modes**: AI Agent, WebUI, API, and CLI with layered architecture (controllers, services, models)
- [x] **AI-powered video script generation**, with support for custom scripts
- [x] **Multiple HD video formats**
  - [x] Portrait 9:16, `1080x1920`
  - [x] Landscape 16:9, `1920x1080`
- [x] **Batch video generation**, create multiple videos and select your favorite
- [x] **Adjustable video segment duration** for flexible material switching
- [x] **Multi-language script generation**
- [x] **Multiple TTS providers**: Edge TTS, Azure Speech, SiliconFlow, Google Gemini, Xiaomi MiMo, ElevenLabs, Chatterbox, and Fish Audio with real-time preview
- [x] **Subtitle generation** with customizable font, position, color, size, stroke, and background
- [x] **Background music** with random or manual selection and volume adjustment
- [x] **Local materials support**, or fetch free HD materials from Pexels, Pixabay, and Coverr
- [x] **AI-generated materials**: Integrated WaveSpeed AI text-to-video models (default Seedance) for generating fresh footage based on script keywords
- [x] **Multiple LLM providers**: Kimi/Moonshot AI, OpenAI, Anthropic Claude, Google Gemini, DeepSeek, Alibaba Qwen, Microsoft Azure OpenAI, VolcanoEngine Ark, and more
- [x] **One-click cross-platform publishing** to TikTok, Instagram, and YouTube Shorts
- [x] **Export/Import presets** and backup/restore all API Keys

## System Requirements 📦

- **Recommended OS**: Windows 10, macOS 11.0+, or mainstream Linux distributions
- **Python**: 3.11 or higher (Python 3.11 recommended)
- **GPU**: Optional, but recommended for local transcription, faster video processing, or smooth batch generation

| Component | Minimum | Recommended | Ideal |
|-----------|---------|-------------|-------|
| CPU | 4 cores | 6-8 cores | 8+ cores |
| RAM | 4 GB | 8 GB | 16+ GB |
| GPU | Not required | 4+ GB VRAM | 8+ GB VRAM |

**Notes:**
- If you primarily rely on cloud LLMs, cloud TTS, and online material sources, CPU and RAM are more important than GPU
- If you enable `faster-whisper`, batch generation, or heavier local processing, GPU significantly improves speed

## Installation & Deployment 📥

### Prerequisites

- Python 3.11 or higher for local deployment
- Windows users should avoid paths with Chinese characters, special characters, or spaces

#### ① Clone Repository

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
```

#### ② Configure Project (Optional)

On first launch, the project automatically creates `config.toml` from `config.example.toml`. Configure LLM providers, material sources, and API Keys directly in the WebUI settings.

### Docker Deployment 🐳

#### ① Start Docker

If Docker isn't installed, install it from https://www.docker.com/products/docker-desktop/

For Windows users, see Microsoft's WSL documentation:
1. https://learn.microsoft.com/en-us/windows/wsl/install
2. https://learn.microsoft.com/en-us/windows/wsl/tutorials/wsl-containers

```shell
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
```

> The recommended approach is `docker-compose.release.yml`, which pulls pre-built images from GitHub Container Registry: `ghcr.io/harry0703/moneyprinterturbo:latest`.

#### ② Access WebUI

Open your browser and navigate to http://127.0.0.1:8501

#### ③ Access API Documentation

Open your browser and navigate to http://127.0.0.1:8080/docs or http://127.0.0.1:8080/redoc

### Manual Deployment 📦

#### ① Create Virtual Environment

Recommended: Use [uv](https://docs.astral.sh/uv/) for Python environment and dependency management. Supports Python 3.11+.

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Alternatively, use `venv + pip`:

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Notes:**
- `pyproject.toml` is the main dependency definition file
- `uv.lock` is the lock file (recommended: execute `uv sync --frozen`)
- `requirements.txt` is kept for legacy `pip` compatibility

#### ② Launch WebUI 🌐

Run these commands from the MoneyPrinterTurbo root directory:

##### Windows

```powershell
.\webui.bat
```

`webui.bat` prioritizes project `.venv` or bundled Python; if not found but `uv` is installed, it automatically switches to `uv run streamlit`.

To allow local network access:
```powershell
set MPT_WEBUI_HOST=0.0.0.0
webui.bat
```

##### macOS or Linux

```shell
sh webui.sh
```

The script automatically uses project virtual environment or `uv` and selects an available local port. For local network access:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

The browser will open automatically (if blank, try Chrome or Edge).

#### ③ Start API Server 🚀

```shell
uv run python main.py
```

If you've activated the virtual environment manually:

```shell
python main.py
```

#### ④ Command-Line Mode (No Browser) ⌨️

For environments without browser or port forwarding, generate videos directly from CLI:

```shell
uv run python cli.py --video-subject "How AI Changes Daily Life"
```

View all commands and parameters:

```shell
uv run python cli.py --help
```

## Text-to-Speech (TTS) 🗣

Default: **Edge TTS** (free, displayed as **Azure TTS V1** in WebUI). Also supports **Azure TTS V2**, **SiliconFlow TTS**, **Google Gemini TTS**, **Xiaomi MiMo TTS**, **ElevenLabs**, and **Fish Audio**.

Select provider and voice directly in WebUI. Edge TTS requires no API Key; other cloud services require credentials (see interface prompts).

## Subtitle Generation 📜

Two subtitle generation methods:

- **edge**: Generate subtitles from TTS timestamps—fast, no GPU required, default mode
- **whisper**: Use local `faster-whisper` for audio transcription—better accuracy for precise timing

Switch in `config.toml`:

```toml
[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"  # or "large-v3" (~3GB, default)
```

> First-time Whisper use auto-downloads the model from Hugging Face. If download fails, manually download from [Hugging Face](https://huggingface.co/Systran/faster-whisper-large-v3) and extract to `.\MoneyPrinterTurbo\models\whisper-large-v3`.

## FAQ 🤔

<details>
<summary>How do I publish to TikTok, Instagram, or YouTube Shorts?</summary>

Register for [Upload-Post](https://upload-post.com/) and get an API Key. Add to `config.toml` under `[app]`:

```toml
[app]
upload_post_enabled = true
upload_post_api_key = "your-api-key"
upload_post_username = "your-username"
upload_post_platforms = ["tiktok", "instagram", "youtube"]
upload_post_auto_upload = true
upload_post_youtube_privacy_status = "public"
```

Save and restart. Videos will auto-publish to configured platforms after generation. YouTube privacy: `public`, `unlisted`, or `private`.

</details>

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

FFmpeg typically downloads and installs automatically. If not, you may see:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

Solution: Download from https://www.gyan.dev/ffmpeg/builds/, extract, and set `ffmpeg_path`:

```toml
[app]
# Set to your actual installation path (use \\ for Windows paths)
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

This is a system file descriptor limit issue. Increase it:

Check current limit:
```shell
ulimit -n
```

Increase if too low:
```shell
ulimit -n 10240
```

</details>

<details>
<summary>Whisper Model Download Failed</summary>

```
LocalEntryNotFoundError: Cannot find an appropriate cached snapshot folder for the specified revision on the local disk...
```

Solution: [Manually download model from Hugging Face](#subtitle-generation-)

</details>
